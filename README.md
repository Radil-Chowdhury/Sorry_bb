# Sorry Page

A tiny, framework-free website (HTML + CSS + JS).

## Run it on your computer
Double-click `index.html`. That's it.

## Make it yours
- Words and photos: edit the `CONFIG` block at the top of `script.js`.
- Photos: put images in the `photos/` folder named `photo1.jpg`, `photo2.jpg`, `photo3.jpg`
  (or change the names in `CONFIG`). Missing photos show a sunset placeholder.

## Put it online (GitHub Pages)
Upload every file here to a public GitHub repo, then Settings > Pages >
Deploy from a branch > `main` / `(root)` > Save.
Your link: https://YOUR-USERNAME.github.io/REPO-NAME/
